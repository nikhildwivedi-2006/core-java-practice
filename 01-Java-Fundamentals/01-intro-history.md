# Introduction & History of Java

## Introduction

Java is a high-level, object-oriented, class-based programming language developed by **James Gosling** and his team at **Sun Microsystems**. It was officially released in **1995**.

Java was designed with the principle of **"Write Once, Run Anywhere (WORA)"**, which means a Java program can run on any operating system that has a Java Virtual Machine (JVM).

Today, Java is one of the most popular programming languages and is widely used for developing web applications, enterprise software, Android applications, desktop applications, cloud-based systems, and backend services.

---

## Why was Java Created?

Before Java, most programming languages were platform-dependent, meaning a program written for one operating system often could not run on another without modification.

James Gosling wanted to create a language that was:

- Platform Independent
- Simple and Easy to Learn
- Secure
- Object-Oriented
- Robust and Reliable
- Portable across different devices

This idea led to the development of Java.

---

## History of Java

- **1991** – James Gosling, Mike Sheridan, and Patrick Naughton started the Green Project at Sun Microsystems.
- The language was initially named **Oak**, after an oak tree outside James Gosling's office.
- Since the name **Oak** was already trademarked, it was renamed **Java**, inspired by Java coffee.
- **1995** – Java was officially launched by Sun Microsystems.
- **2009** – Oracle Corporation acquired Sun Microsystems and became the owner of Java.
- Today, Java continues to evolve with regular feature updates and remains one of the most widely used programming languages.

- Platform Independence
- Object-Oriented Programming
- High Security
- Automatic Garbage Collection

- Rich Standard Library
- Strong Community Support
- Excellent Performance with JVM

# Interview Questions

### 1. Who developed Java?

**Answer:** James Gosling and his team at Sun Microsystems.

### 2. When was Java officially released?

**Answer:** 1995.

### 3. What was Java originally called?

**Answer:** Oak.

### 4. Why was Oak renamed to Java?

**Answer:** The name Oak was already trademarked, so it was renamed to Java.

### 5. What is the full form of WORA?

**Answer:** Write Once, Run Anywhere.

### 6. Who currently owns Java?

**Answer:** Oracle Corporation.

### 7. Why is Java considered platform independent?

**Answer:** Because Java programs run on the Java Virtual Machine (JVM), allowing the same bytecode to execute on different operating systems without modification.

---

## Summary

Java is a powerful, object-oriented, and platform-independent programming language developed by James Gosling at Sun Microsystems. It was designed to build secure, reliable, and portable applications. Its "Write Once, Run Anywhere" philosophy and continuous evolution have made Java one of the most widely used programming languages in the software industry.
