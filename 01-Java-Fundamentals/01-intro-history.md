# Introduction & History of Java

## What is Java?

Java is a high-level, object-oriented, secure, robust, class-based programming language developed by **Sun Microsystems**.

Java was designed to be simple, secure, portable, and platform-independent. It follows the principle:

> Works on the principle of WORA ("Write Once, Run Anywhere")

This means Java programs can run on any device that has a Java Virtual Machine (JVM).

---

## History of Java

- Java was developed by **James Gosling** and his team at Sun Microsystems.
- The development of Java started in **1991** as a project called **Oak**.
- Oak was originally designed for electronic devices and embedded systems.
- In **1995**, Oak was renamed **Java** and officially released.
- Java became popular because of its platform independence and security features.
- In **2010**, Oracle Corporation acquired Sun Microsystems and became the owner of Java.

## Interview Questions

### Q1. Who developed Java?

**Answer:**

---

### Q2. Why Java is called Platform Independent?

**Answer:**  
Java is called platform-independent because Java source code is converted into bytecode, which runs on JVM available for different operating systems.

**Answer:**
